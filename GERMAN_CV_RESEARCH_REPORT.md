## 🔴 NODE: CORE_FORMAT_REQUIREMENTS

### Format Fundamentals
- **Document Name**: `Lebenslauf` (never "CV" or "Resume" in German context)
- **Structure**: `Tabellarischer Lebenslauf` (tabular, two-column layout)
- **Layout**: Left column = dates (MM/YYYY - MM/YYYY), Right column = details
- **Order**: **Reverse chronological** (neueste zuerst) within each section
- **Length**: 1-2 pages A4 (1 page for students/early career, 2 for experienced)
- **File Format**: **PDF only** (never Word - layout breaks on different systems)
- **Font**: Professional (Arial, Calibri, Times New Roman, Helvetica), 10-12pt body, 14-16pt headings
- **Margins**: 2-2.5cm standard
- **Line Spacing**: 1.15-1.5
- **Signature**: Place + Date (left) + Signature (right) at bottom - expected traditionally

### DIN 5008 Compliance
- Aligns with German business correspondence standard
- Consistent date formats (MM/YYYY throughout)
- No mixed fonts, no decorative elements
- Clean section separations (bold headings or whitespace)

## 🔴 NODE: MANDATORY_SECTIONS (Ordered by Priority)

### 1. PERSÖNLICHE DATEN (Personal Details) - TOP OF DOCUMENT
**Mandatory:**
- Full name (Vorname + Nachname)
- Full postal address (Straße, PLZ, Ort)
- Phone number (with +49 country code if applying from abroad)
- Professional email address

**Traditional/Expected (AGG makes optional but widely expected):**
- Date of birth (Geburtsdatum)
- Place of birth (Geburtsort)
- Nationality (Staatsangehörigkeit) - **critical for visa clarity**
- Professional photo (Bewerbungsfoto) - top right corner

**DO NOT INCLUDE (discriminatory/outdated):**
- Parents' names/occupations
- Religion
- Marital status (Familienstand) - increasingly omitted
- ID numbers (passport, etc.)

### 2. BERUFSERFAHRUNG (Work Experience) - HEART OF CV
- **Reverse chronological** (current/most recent first)
- Per position: Date range (MM/YYYY-MM/YYYY), Exact title, Employer + location, 2-4 bullet points
- **Bullets**: Action verbs, quantified results, tools/tech mentioned
- Older roles (>5-7 years): Summarize briefly or bundle
- **Gaps**: Must be explained (parental leave, study, relocation, "Bewerbungsphase") - Germans hate unexplained gaps

### 3. AUSBILDUNG / BILDUNGSWEG (Education)
- **Reverse chronological**
- Per entry: Date range, Degree/Qualification, Institution + City
- Grade only if "gut" (1.x-2.x) or better
- Thesis topic + relevant modules if aligned with role
- Highest school leaving certificate always included

### 4. KENNTNISSE UND FÄHIGKEITEN (Skills)
**Categorized:**
- **IT/Tools**: Software, platforms, programming languages
- **Sprachen**: CEFR levels (Deutsch C1/B2, Englisch C1) - be honest
- **Zertifikate/Weiterbildungen**: Role-relevant only, most recent first
- **Führerschein**: If relevant for role
- **Domain skills**: Role-specific know-how

### 5. EHRENAMT / INTERESSEN (Optional but Valued)
- Only if meaningful: Ehrenamt, team sports, leadership roles
- Shows soft skills (Teamfähigkeit, Organisationstalent) without claiming them directly
- Max 3-4 concrete items with brief context

## 🔴 NODE: PHOTO_RULES

### Legal Status
- **AGG (Allgemeines Gleichbehandlungsgesetz 2006)**: Photo, DOB, marital status **legally optional**
- **BUT**: Still **widely expected** in traditional sectors (banking, insurance, public admin, manufacturing, Mittelstand)

### Decision Matrix
| Sector | Photo Expected? |
|--------|-----------------|
| Traditional corporate (banking, insurance, consulting) | YES |
| Public sector / Government | YES |
| Mittelstand / Family businesses | YES |
| Tech startups / International tech | NO (increasingly omitted) |
| FAANG / Big Tech German offices | NO |
| Creative/Design | Portfolio matters more |

### If Including:
- Professional headshot (business attire, neutral background)
- Upper right corner of page 1
- Current, high quality
- **If omitting**: Remove cleanly - NO blank placeholder

## 🔴 NODE: ANSCHREIBEN_REQUIREMENTS

### Mandatory in Germany (unlike US)
- **Always required** for: Traditional companies, structured hiring, internships, apprenticeships
- **Length**: Exactly 1 page DIN A4
- **Language**: Match job posting (German ad → German Anschreiben)

### Structure (DIN 5008 letter format)
```
ABSender (top right): Your contact details
EMPFÄNGER (left): Hiring manager name + company + address
ORT, DATUM (right aligned)
BETREFF: "Bewerbung als [Role] – [Ref#]" (bold, underlined)
ANREDE: "Sehr geehrte Frau Müller," / "Sehr geehrte Damen und Herren,"
```

### Content Paragraphs
1. **Opening**: Why THIS company (1-2 sentences, specific research)
2. **Body 1**: Why THIS role - map 3+ JD requirements → your proof points
3. **Body 2**: Your flagship achievement (thesis, flagship project)
4. **VISA BOX** (critical for internationals):
   ```
   Visastatus: Deutscher MSc-Abschluss → uneingeschränkt vollzeitbeschäftigbar 
   ab 28.08.2026 (§20 AufenthG → §18g AufenthG, kein Arbeitgeber-Sponsoring nötig).
   Blue Card tauglich zum IT-Fachkräfte-Threshold (€45.934/Jahr, 2026).
   ```
5. **Closing**: "Über eine Einladung zum persönlichen Gespräch freue ich mich."
6. **Grußformel**: "Mit freundlichen Grüßen"
7. **Anlagen**: List attachments (Lebenslauf, Zeugnisse, etc.)

### File Naming
- `Vorname_Nachname_Anschreiben.pdf`
- `Vorname_Nachname_Lebenslauf.pdf`
- Combined package: `Vorname_Nachname_Bewerbung_[Company].pdf`

## 🔴 NODE: VISA_COMMUNICATION (Critical for Internationals)

### Required Elements in BOTH CV + Anschreiben
1. **Explicit authorization statement**:
   > "Uneingeschränkt vollzeitbeschäftigbar ab 28.08.2026 (§20 AufenthG Job-Sucher-Visum → §18g Aufenthaltserlaubnis, **kein Arbeitgeber-Sponsoring nötig**)"

2. **Blue Card eligibility**:
   > "Deutscher Hochschulabschluss = EU Blue Card berechtigt zum reduzierten IT-Fachkräfte-Threshold (€45.934/Jahr, 2026)"

3. **Availability**: "Verfügbar für Gespräche sofort, Start ab September 2026 möglich"

### Where to Place
- **CV**: Header (under contact) or dedicated "Visastatus" line
- **Anschreiben**: Dedicated highlighted box (Visabox) after body paragraphs
- **Never hide**: German employers need this clarity upfront

## 🔴 NODE: APPLICATION_PACKAGE (Bewerbungsmappe)

### Complete Package Expectation
German employers often expect **complete package**:
1. **Anschreiben** (Cover letter) - 1 page
2. **Lebenslauf** (CV) - 1-2 pages  
3. **Zeugnisse** (Certificates) - Most recent first:
   - MSc certificate + transcript
   - BEng certificate + transcript
   - Arbeitszeugnisse (employment references) - most recent first
   - Language certificates (IELTS, Goethe)
   - Relevant certifications

### Submission Methods
| Method | When to Use |
|--------|-------------|
| Company portal (Greenhouse, Lever, Personio, Workday) | Primary - follow their form |
| Email to hiring manager | **Strongly preferred** - find via XING/LinkedIn |
| Postal | Rare, only if explicitly requested |

## 🔴 NODE: ATS_OPTIMIZATION_GERMANY

### German ATS Reality
- **Prevalence**: Medium (lower than US)
- **Parsers**: Read text, not images
- **Tables**: Two-column tabular CAN confuse weak parsers
- **Solution**: Keep tabular LOOK but use simple text-based tables

### Keyword Strategy
- Mirror job ad wording for: Skills, titles, tools
- Standard section headings: `Berufserfahrung`, `Ausbildung`, `Kenntnisse`, `Sprachkenntnisse`
- **Never**: Put critical info in graphics, photo, headers/footers, text boxes
- **Always**: Real selectable text in PDF

## 🔴 NODE: COMMON_MISTAKES (Reddit/Forum Consensus)

| Mistake | Consequence | Fix |
|---------|-------------|-----|
| US resume format (1 page, no photo, no DOB) | Looks sparse/unprofessional | Use German tabellarisch 2-page format |
| No cover letter | Auto-reject at 80%+ companies | Always include Anschreiben |
| Unexplained gaps >2 months | Immediate suspicion | Label honestly: "Elternzeit", "Weiterbildung", "Bewerbungsphase" |
| Tasks instead of achievements | Weak impression | Quantify: "Reduced latency 50%", "500+ SKUs at 95% precision" |
| Generic CV for all applications | Low relevance score | Tailor per JD (keywords, section emphasis) |
| Word doc instead of PDF | Layout breaks | Always PDF |
| Missing signature | Looks careless (traditional) | Sign: Place, Date + signature |
| English CV for German ad | Language mismatch | Match ad language |
| Hiding visa status | Employer uncertainty | Explicit visa box in CV + CL |
| Photo placeholder if no photo | Unprofessional | Remove cleanly or include pro photo |
| 3+ pages for normal role | Unfocused | Max 2 pages |

## 🔴 NODE: SECTOR_SPECIFIC_NUANCES

### Tech/IT/Startups
- Photo: Often omitted
- English CV accepted if ad is English
- GitHub/portfolio links in contact section
- Modern layout acceptable (clean, not flashy)
- Focus: Tech stack, quantified impact, open source

### Traditional/Mittelstand
- Photo: Expected (professional headshot)
- German CV mandatory even if ad in English
- Conservative layout (Times New Roman, black/white)
- Full personal details (DOB, nationality)
- Signature expected

### Research/Academic
- Longer CV acceptable (3+ pages)
- Publications, conferences, grants detailed
- Thesis prominently featured
- May need `ausführlicher Lebenslauf` (narrative)

### Public Sector
- Strict formal requirements
- Photo expected
- Full personal details
- Certificates mandatory
- Often specific forms/templates

## 🔴 NODE: REDDIT_COMMUNITY_INSIGHTS

### r/de / r/germany / r/cscareerdeutschland Themes

**On Photo Debate:**
> "Include photo for traditional, omit for tech. When in doubt, include - it's safer. A bad photo is worse than no photo."

**On Visa Communication:**
> "Put visa status in BOLD in CV header. HR filters for 'kein Sponsoring nötig' - if they don't see it, you're auto-filtered."

**On Cover Letter:**
> "German HR spends 30 seconds on CV, 2 minutes on Anschreiben. The CL is where you prove you read the JD."

**On Gaps:**
> "Any gap >8 weeks needs a label. 'Auszeit' looks lazy. 'Selbstständige Weiterbildung Python/ML' shows initiative."

**On Length:**
> "2 pages is the hard ceiling. 3 pages = 'kann sich nicht fokussieren'. Academic CVs excepted."

**On Salary:**
> "State Bruttojahresgehalt in CL if asked: '€55.000-65.000 Bruttojahresgehalt'. Never monthly."

**On Referrals:**
> "XING > LinkedIn for DACH. Find alumni at target company. Cold application response rate <5%, referral >30%."

## 🔴 NODE: WEEKLY_WORKFLOW_RECOMMENDATIONS

### Monday: Plan (5 Target Roles)
- Select from high-score evaluated roles
- Priority: English-friendly, visa-clear, high fit

### Tuesday: Research
- Find hiring manager (XING > LinkedIn)
- Check Kununu/Glassdoor
- Recent news (funding, layoffs, product launches)
- Tech stack from engineering blog
- German language requirement check

### Wednesday: Package Generation
- Tailor CV bullets for JD keywords
- Write Anschreiben (map 3+ JD reqs → proof points)
- Generate PDF package (CV + CL merged)

### Thursday: Submit
- Company portal + email to hiring manager
- Track in applications.md (URL, date, contact)
- Set follow-up reminders (7d, 14d, 21d)

### Friday: Follow-ups & Plan Next Week
- Check applications.md for due follow-ups
- Update statuses
- Plan next week's 5 roles

## 🔴 NODE: SALARY_NEGOTIATION_NORMS

### German Conventions
- **Format**: Bruttojahresgehalt (annual gross), NOT monthly
- **Range**: "€55.000-65.000 Bruttojahresgehalt"
- **Blue Card Floor**: €45.934 (IT shortage) / €50.700 (general) 2026
- **Timing**: Negotiate AFTER offer, not before
- **Expectation**: German companies expect negotiation (5-10% buffer built in)

## 🔴 NODE: REFERRAL_STRATEGY_DACH

### Platform Priority
1. **XING** - Primary professional network in DACH (more active for hiring)
2. **LinkedIn** - Secondary but growing, better for international companies
3. **Alumni Networks** - BSBI, TU Berlin, HPI, university career services
4. **Meetups** - Berlin ML, CV, Robotics, PyData meetups
5. **Recruiters** - Build relationships with 5-10 technical recruiters

### Approach
- Connect with alumni at target company
- Ask for "Kaffeechat" (informational interview)
- Request referral AFTER conversation
- German recruiters value warm intros over cold applications
