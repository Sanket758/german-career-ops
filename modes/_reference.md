## German CV Formatting Checklist

When generating any German `Lebenslauf`, verify:

- [ ] **Length:** 1 page maximum (for <10 years experience)
- [ ] **Dates:** All in `MM.YYYY` format (not "Oct 2021")
- [ ] **Photo:** Only if user explicitly opts in
- [ ] **Personal data section:** Address, phone, email (DOB/nationality only if user opts in)
- [ ] **Signature line:** `Berlin, den [DATUM]` + `[Unterschrift]` at bottom
- [ ] **Chronology:** Reverse chronological within each section
- [ ] **Language level:** Explicitly stated (e.g., "Deutsch: B1")
- [ ] **Visa status:** Mentioned in profile section if relevant
- [ ] **No hype verbs:** No "Shipped", "Architected", "Pioneered", "Boosted"

## Impact vs Hype Translation Table

| American Style (AVOID) | German Standard (USE) |
| ---------------------- | --------------------- |
| "Shipped production ML pipeline" | "Developed and deployed ML pipeline" |
| "Architected real-time system" | "Designed real-time processing system" |
| "Boosted revenue 40%" | "Contributed to 40% revenue increase through..." |
| "Directed a team of 4" | "Coordinated with 4 team members" |
| "Pioneered innovative approach" | "Implemented approach for..." |
| "Passionate about AI" | "Focus area: AI/ML" |
| "Rock star engineer" | (delete entirely) |

## German-Specific Red Flags (Auto-Downgrade)

| Red Flag | Penalty | Reasoning |
| -------- | ------- | --------- |
| Requires C1 German when user is A2/B1 | -2.0 points | Automatic DQ in most cases |
| "Senior" or "Principal" title when user is MSc student | -1.5 points | Title inflation mismatch |
| On-site outside Berlin 5 days/week during MSc | -1.5 points | Logistics impossibility |
| Defense/security role with non-EU citizenship | -1.0 points | Visa complications |
| Pure research role at AI lab without PhD | -1.5 points | Credential mismatch |
| Salary <€15/hour for Werkstudent | -0.5 points | Below market rate |
| Company has rejected user before | -2.5 points | Burned bridge |
| Role posted >90 days ago | -1.0 points | Likely already filled |

## Benjamin Button Strategy

Position the CV so the most relevant information for the target role appears first:
- For Werkstudent: Lead with current MSc + thesis topic
- For full-time: Lead with 4 years production ML experience
- Always: Tailor the Profil/Summary section to mirror the JD's language

## Document Packet Requirements

German applications may require:
- `Anschreiben` (cover letter)
- `Lebenslauf` (CV)
- `Arbeitszeugnisse` (work references)
- Transcripts
- Earliest start date
- Visa or work authorization answer

## German Writing Style

### For German output:
- Use natural Tech-German, keep sentences concise
- Avoid literal translations, inflated adjectives
- Avoid fake humility and fake swagger
- Be specific, factual, and calm

### For English output to German companies:
- Keep the tone restrained and concrete
- Avoid US cover letter clichés
- Emphasize work authorization, location, and reason for Germany-based fit
