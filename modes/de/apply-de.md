# Apply Mode — German Market (DE)

German job applications require specific materials and process:

## Required Package per Application
1. **Lebenslauf** (tabellarisch, 2 pages max, reverse chronological)
2. **Anschreiben** (1 page, addressed to hiring manager, references JD)
3. **Zeugnisse** (MSc, BEng, Arbeitszeugnisse - listed in attachments)
4. **Optional**: Projektportfolio, Sprachnachweise

## German-Specific Rules

### CV (Lebenslauf)
- **Format**: Tabellarischer Lebenslauf (table format, not US resume)
- **Length**: Max 2 pages
- **Order**: Reverse chronological (neueste zuerst)
- **Sections required**:
  1. Persönliche Daten (Name, Adresse, Telefon, E-Mail, LinkedIn, GitHub, **Visastatus**)
  2. Berufserfahrung (4-5 bullets per role, metrics, action verbs)
  3. Ausbildung (MSc first, then BEng, with thesis highlight)
  4. Technische Kompetenzen (grouped: ML/CV, MLOps, Robotics, Languages)
  5. Ausgewählte Projekte (3-4 key, one-line + metric)
  6. Sprachen (Deutsch B1, Englisch C1)
  7. Ehrenamt/Interessen (optional, shows culture fit)
- **Photo**: Optional for tech/startups, expected for Mittelstand/corp
- **Visastatus**: Must be prominent: "Uneingeschränkt vollzeitbeschäftigbar ab 28.08.2026 (§20 → §18g AufenthG, kein Sponsoring nötig)"

### Cover Letter (Anschreiben)
- **Length**: Exactly 1 page DIN A4
- **Structure**:
  - Absender (top right)
  - Empfänger (left, with hiring manager name if known)
  - Ort, Datum (right)
  - Betreff: "Bewerbung als [Role] – [Ref#]"
  - Anrede: "Sehr geehrte Frau Müller," / "Sehr geehrte Damen und Herren,"
  - Opening: Why THIS company (1-2 sentences, specific)
  - Body: 2-3 paragraphs mapping JD requirements → your proof points
  - **Visabox**: Explicit visa status + Blue Card eligibility
  - Closing: "Über eine Einladung zum persönlichen Gespräch freue ich mich."
  - Grußformel: "Mit freundlichen Grüßen"
  - Anlagen listing
- **Language**: Match JD language (German JD → German cover letter)

### Application Submission
- **Portal**: Company career site (Greenhouse, Lever, Ashby, Personio, Workday)
- **Email**: If no portal, email to hiring manager/recruiter (find via XING/LinkedIn)
- **File naming**: `Vorname_Nachname_Lebenslauf.pdf`, `Vorname_Nachname_Anschreiben.pdf`
- **Combined**: Single PDF package preferred (CV + Cover Letter)

### Follow-up (German Business Etiquette)
- **7 days**: Friendly check-in (email)
- **14 days**: Second follow-up (phone if number available)
- **21 days**: Final follow-up, then move on
- **Tone**: Professional, not pushy, reference application date

### Salary Negotiation (German Norms)
- **Format**: Bruttojahresgehalt (annual gross)
- **Range**: €50K-65K (state as "€55.000-65.000 Bruttojahresgehalt")
- **Blue Card**: Must meet €45.934 (IT shortage) / €50.700 (general) 2026
- **Negotiation**: After offer, not before. German companies expect negotiation.

### Language Gates
- **B1 German**: Auto-reject at 60%+ companies
- **English-speaking teams**: International startups, Big Tech (Google, Microsoft, SAP, etc.)
- **Strategy**: Apply to English-speaking teams, flag German-required roles as "need B2"
- **Cover letter**: Always in JD language

### Referral Strategy (Critical in Germany)
- **XING**: Primary professional network in DACH
- **LinkedIn**: Secondary, but growing
- **Alumni**: BSBI, TU Berlin, HPI, university networks
- **Meetups**: Berlin ML, CV, Robotics meetups
- **Recruiters**: Build relationships with 5-10 technical recruiters at target companies

## Workflow per Application

```
1. FIND role (portal scanner, XING, LinkedIn, company site, referral)
2. HEALTH CHECK (is posting live? applyable? not expired?)
3. RESEARCH company (hiring manager, tech stack, Kununu, recent news)
4. TAILOR CV (adjust bullets for JD keywords)
5. WRITE ANSCHREIBEN (map JD reqs → proof points, add visa box)
6. GENERATE PACKAGE (single PDF: CV + Cover Letter)
7. SUBMIT via portal / email to hiring manager
8. TRACK in applications.md (status: Applied, date, contact)
9. FOLLOW-UP at 7/14/21 days
10. INTERVIEW PREP (German style: technical + cultural + salary)
```

## Weekly Cadence (Monday-Friday)

**Monday**: Select 5 target roles for the week
**Tuesday**: Research companies, find hiring managers, tailor CVs
**Wednesday**: Write Anschreiben, generate packages
**Thursday**: Submit applications (portal + email referrals)
**Friday**: Follow-ups on previous week, update tracker, plan next week
