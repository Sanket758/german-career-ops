# Modes Directory Index

This directory contains the "Personas" and "Instructions" for different stages of the job search pipeline.

| File/Folder | Description |
|-------------|-------------|
| `_shared.md` | Shared system context and foundational rules (System Layer). |
| `_profile.md` | User-specific overrides and personalization (User Layer). |
| `oferta.md` | Scoring and evaluation logic for job offers (A-F ranking). |
| `pdf.md` | Rules for generating ATS-optimized CVs and cover letters. |
| `apply.md` | Assistant for filling out application forms and answering questions. |
| `scan.md` | Instructions for portal scanning and match detection. |
| `full.md` | One-command full workflow: scan → evaluate → pipeline → PDF → Gmail tracker. |
| `deep.md` | Prompts for deep company and role research. |
| `de/` | German language-specific modes (DACH market). |
