# Templates Directory Index

Contains templates for CVs, status tracking, and configuration.

| File | Description |
|------|-------------|
| `cv-template.html` | Base HTML template for generating tailored CVs. |
| `cv-template-german.html` | Deterministic German two-page CV template. |
| `states.yml` | Canonical status definitions for the application tracker. |
| `portals.example.yml` | Example configuration for job portal scanning. |
