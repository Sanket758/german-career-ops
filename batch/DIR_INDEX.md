# Batch Processing Directory Index

Contains scripts and data for parallelized job evaluation and tracker merging.

| File | Description |
|------|-------------|
| `merge-tracker.mjs` | Merges batch-evaluated job reports into `data/applications.md`. |
| `batch-prompt.md` | Template prompt for LLM batch workers. |
| `tracker-additions/` | Folder containing temporary TSV files for tracker merging. |
| `logs/` | Execution logs for batch jobs. |
